# Your Restaurant Here

Telegram-бот для поиска заведений в Астане. Подбор учитывает кухню, бюджет, атмосферу и цветовую палитру; в Tinder Mode можно просматривать случайные заведения и сохранять понравившиеся. Есть профиль, оценки рекомендаций и статистика для администраторов.

## Стек

Python 3.11+ · aiogram 3 · SQLite · aiosqlite · Argon2id · Pillow · pytest

## Запуск на Windows

1. Установите [Python 3.11 или новее](https://www.python.org/downloads/) и скачайте проект.
2. Создайте бота через [@BotFather](https://t.me/BotFather) и получите его токен.
3. В папке проекта скопируйте `.env.example` в файл `.env` и заполните его:

   ```env
   BOT_TOKEN=токен_от_BotFather
   ADMIN_INITIAL_PASSWORD=ваш_начальный_пароль
   ```

   `ADMIN_INITIAL_PASSWORD` — начальный пароль длиной 8–128 символов для двух администраторов: `matveikrutoi228` и `aruzhan9mice`. Он используется при создании аккаунтов; для уже созданных аккаунтов изменение `.env` пароль не меняет. Токен и пароль никому не отправляйте.

4. Запустите `starttelegrambot.bat`. При первом запуске файл создаст `.venv` и установит зависимости. Оставьте окно открытым; для остановки нажмите **Ctrl+C**.
5. При первом запуске создаётся пустая база. Чтобы загрузить заведения, остановите бота и выполните в папке проекта:

   ```powershell
   .\.venv\Scripts\python.exe import_restaurants.py
   ```

   Затем снова запустите `starttelegrambot.bat`. Импорт использует `app/database/astana_places.json`; повторный запуск не создаёт дублей.

Найдите бота в Telegram и отправьте `/start`. Управление аккаунтом — `/account`, завершение сеанса — `/finish`.

## Данные и тесты

Файл `.env`, виртуальное окружение `.venv` и база `perfect_restaurant.db` исключены из Git. База создаётся локально и сохраняет пользователей, избранное и историю между запусками; храните её резервные копии в защищённом месте.

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```
